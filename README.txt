MY GARAGE - Simple Week 10/11 Website

1. Unzip the folder.
2. Double-click index.html to test in your browser.
3. Add a car using the form and watch it appear under Cars Added.

Files:
- index.html: tab title, heading, and form
- style.css: 10+ CSS style choices
- script.js: displays submitted car information

Assignment checklist:
- Tab title and page heading: yes
- CSS with 10+ style choices: yes
- Form: 6 inputs (text, select, number, color, textarea, checkbox)
- Submitted form data displayed on the page: yes
- AWS S3: you must upload/publish the files yourself

AWS S3 note: Upload the THREE individual site files to the ROOT of
an S3 static website bucket (not the containing folder or ZIP).
Set index document to index.html and follow the public-read instructions
in your class AWS S3 Deployment PDF. Submit the website endpoint URL.
Do not upload your AWS credentials or access keys.
